# 10. Речник

| Термин | Просто обяснение |
|---|---|
| **Admin / панел** | Частта от сайта, в която се управлява съдържанието (`/panel`) |
| **Alias (псевдоним)** | Кратко име за нещо по-дълго, напр. `admin` за `AdminGuard` |
| **Apache** | Програмата-сървър, която приема заявките от интернет |
| **Artisan** | Командният инструмент на Laravel (`php artisan …`) |
| **Audit log / журнал** | Запис кой какво е правил в панела |
| **Bcrypt** | Начин за „смилане“ на парола, така че да не може да се върне |
| **Blade** | Шаблонният език на Laravel (`.blade.php`) |
| **Cache / кеш** | Запомнен резултат, за да не се смята всеки път |
| **Class / клас** | „Чертеж“ на група свързани неща (код и данни заедно) |
| **CMS** | Система за управление на съдържание |
| **Composer** | Инструмент, който сваля нужните PHP пакети |
| **Config** | Настройки (папка `config/`) |
| **Controller / контролер** | Клас, който обработва заявка и решава какво да върне |
| **Cookie / бисквитка** | Малък текст, запомнен от браузъра |
| **CSP** | Правило, което казва на браузъра кои скриптове са позволени |
| **CSRF** | Атака с подправен формуляр; защита — таен код `@csrf` |
| **Document root** | Папката, която сървърът показва на интернет (трябва да е `public/`) |
| **Eloquent** | Начинът на Laravel да работи с базата през PHP класове |
| **.env** | Файл с тайните настройки на сървъра |
| **Framework** | Готов комплект инструменти (Laravel) |
| **GD** | PHP разширение за работа със снимки |
| **GET / POST** | Видове заявки: „дай“ / „приеми данни“ |
| **Hash / хеш** | Необратим „отпечатък“ на данни |
| **Hook / хук** | „Закачалка“ за плъгини |
| **HSTS** | Заглавка „винаги ползвай HTTPS“ |
| **HTTPS** | Шифрована връзка (катинарчето в браузъра) |
| **Locale** | Език на страницата (`bg`, `en`) |
| **Middleware** | „Охрана“ — проверка преди/след заявката |
| **Migration / миграция** | Файл, описващ създаване/промяна на таблица |
| **Model / модел** | PHP клас за една таблица |
| **Namespace** | „Адрес“ на клас (`App\Models`) |
| **nonce** | Еднократен таен код за разрешаване на скрипт в CSP |
| **PDO** | PHP начин за връзка с база данни |
| **Plugin / плъгин** | Добавка, която разширява програмата без да пипа ядрото |
| **Rate limit** | Ограничение на броя опити за време |
| **Request / Response** | Заявка / отговор |
| **Revision / версия** | Запазена стара версия на текст |
| **Route / маршрут** | Правило „този адрес → този код“ |
| **Sanitizer** | Почиства HTML от опасен код |
| **Scope** | Наша кратка заявка в модел (напр. `visible()`) |
| **Seeder** | Код/файл, който пълни базата с начални данни |
| **Session / сесия** | Запомнена информация за посетителя на сървъра |
| **Slug** | Четимата част от адреса (`za-nas`) |
| **SMTP** | Протокол за изпращане на поща |
| **SQL** | Езикът за разговор с база данни |
| **Table / ред / колона** | Лист / запис / свойство в базата |
| **Транзакция** | „Всичко или нищо“ при запис в базата |
| **Validation / валидация** | Проверка дали въведените данни са правилни |
| **vendor/** | Папка с Laravel и пакетите — не се пипа |
| **View / изглед** | HTML шаблон |
| **XSS** | Вмъкване на чужд скрипт в страница; защита — Sanitizer + `{{ }}` + CSP |
