# 2. Структура на папките

```
mcms42/
├── app/                  ← ВСИЧКО, което сме написали ние (логиката)
│   ├── Http/
│   │   ├── Controllers/  ← „готвачите“: решават какво да се случи
│   │   │   ├── Admin/    ← контролери на административния панел
│   │   │   ├── SiteController.php     ← публичният сайт
│   │   │   └── InstallController.php  ← инсталаторът
│   │   └── Middleware/   ← „охраната“: проверки преди всяка заявка
│   ├── Models/           ← „килерът“: по един клас за всяка таблица
│   ├── Providers/        ← стартов код на приложението
│   ├── Support/          ← помощни класове (сигурност, качване, архиви, плъгини…)
│   └── helpers.php       ← кратки функции, ползвани навсякъде: t(), setting(), lroute()…
│
├── bootstrap/            ← „запалването на двигателя“
│   ├── app.php           ← настройва приложението (middleware, маршрути, първи старт)
│   └── providers.php     ← списък на стартовите класове
│
├── config/               ← настройки (като код)
│   ├── app.php           ← име, език, часова зона
│   ├── mcms.php          ← НАШИТЕ настройки: роли, админ път, лимити
│   └── session.php       ← настройки на сесиите
│
├── database/
│   ├── migrations/       ← описание на таблиците
│   └── seeders/strings.php  ← начални текстове на интерфейса (bg/en)
│
├── lang/bg/              ← български съобщения за грешки при формуляри
│
├── plugins/              ← плъгини (по един под-папка)
│
├── public/               ← ЕДИНСТВЕНАТА папка, достъпна от интернет
│   ├── index.php         ← входната врата на цялата програма
│   ├── .htaccess         ← правила на сървъра Apache
│   ├── assets/css,js/    ← стилове и скриптове
│   ├── assets/vendor/    ← външни библиотеки (CKEditor 5)
│   └── uploads/          ← качените снимки и PDF-и
│
├── resources/views/      ← „чиниите“: HTML шаблоните (Blade)
│   ├── admin/            ← панелът
│   ├── site/             ← публичният сайт
│   ├── install/          ← инсталаторът
│   ├── errors/           ← страници за грешки (404 и др.)
│   └── pagination/       ← бутоните „Назад / Напред“
│
├── routes/
│   ├── web.php           ← КАРТАТА на всички адреси
│   └── console.php       ← команди за терминал (php artisan mcms:…)
│
├── storage/              ← временни и вътрешни файлове
│   ├── app/backups/      ← архивите
│   ├── framework/        ← сесии, кеш, компилирани шаблони
│   ├── logs/             ← дневници с грешки
│   └── installed.lock    ← файл, който показва, че инсталацията е приключила
│
├── tests/standalone.php  ← самопроверка на сигурностните класове
├── vendor/               ← Laravel и пакетите му (създава се от composer, НЕ се пипа)
├── artisan               ← команден инструмент на Laravel
├── composer.json         ← списък на нужните пакети
├── .env                  ← тайни настройки на сървъра (създава се сам)
├── .env.example          ← шаблон за .env
└── docs/                 ← тази документация
```

## Какво може и какво не бива да се пипа

| Папка / файл | Може ли да се променя? |
|--------------|------------------------|
| `app/`, `resources/views/`, `routes/`, `public/assets/` | **Да** — тук е вашата работа |
| `config/mcms.php`, `.env` | Да, внимателно |
| `plugins/` | Да — тук добавяте функции без да пипате ядрото |
| `database/migrations/` | Не променяйте старите; добавяйте **нови** файлове |
| `vendor/` | **Никога** — вътре е Laravel |
| `storage/`, `bootstrap/cache/` | Не ръчно; програмата сама ги управлява |
| `public/uploads/` | Не ръчно; качвайте през панела |

## Защо само `public/` е достъпна от интернет?

Ако сървърът показва цялата папка на проекта, някой може да отвори `https://primer.bg/.env`
и да прочете паролите ви. Затова **document root** (папката, която сървърът показва) се насочва
към `public/`, а всичко останало остава „зад ключ“. Ако хостингът не позволява това, коренният
`.htaccess` блокира вътрешните папки (по-слаба защита).

## Какво е `app/Support`?

Това е нашата „кутия с инструменти“. Всеки клас върши една задача:

| Клас | Задача |
|------|--------|
| `Sanitizer` | Почиства HTML от опасен код |
| `Totp` | Генерира и проверява кодове за двуфакторна защита |
| `Uploader` | Безопасно приема и обработва качени файлове |
| `Backup` | Прави архиви на базата и на файловете |
| `ContentSaver` | Записва страница/публикация с всички преводи и версии |
| `Installer` | Попълва базата с начални данни при инсталация |
| `EnvWriter` | Безопасно променя `.env` |
| `Hooks` | Системата за „закачалки“ (плъгини) |
| `PluginManager` | Намира и зарежда плъгините |
